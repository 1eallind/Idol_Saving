# 偶像存档中！｜Idol Saving!

《偶像存档中！》（Idol Saving!）是一款以虚拟偶像运营为主题的剧情向养成游戏，结合日程安排、随机事件与卡牌应对等玩法。玩家扮演经纪人，通过安排主播的活动、处理直播事件，在运营成绩与主播自身状态之间做出选择。

> 项目仍在开发中，仓库内的原型、素材与文档会随着制作进度持续更新。

## 当前内容

- `game/demo_v10.html`：当前 HTML 游戏演示原型。
- `game/danmaku_v1.json`：弹幕数据。
- `assets/`：角色、场景、UI、品牌视觉、字体和插画等素材。
- `audio-projects/`：语音相关工程或音频文件。
- `docs/`：游戏策划、剧情与数值等文档。
- `design/`：设计规范、参考资料及制作记录。

## 素材管理约定

为便于多人协作，素材目录尽量遵循以下约定：

- `aigc/`：AI 生成、具有保留价值的原始生成稿。
- `references/`：用于设计和制作的参考图，不直接作为游戏运行资源。
- `export/`：经过筛选、用于游戏或演示的成品素材。
- 文件夹只在确实需要时创建；不要求每类素材都同时具备上述目录。
- 已直接用于游戏的 AI 生成图片可以直接放入 `export/`，不必重复保存一份。
- 文件名尽量使用简洁、可读的英文和下划线，避免 `image1.png` 等难以辨认的名称。

## 运行原型

当前仓库包含 HTML 演示原型：

1. 下载或克隆仓库。
2. 在本地文件管理器中找到 `game/demo_v10.html`。
3. 使用现代浏览器打开文件进行预览。

如果后续原型引入额外依赖、服务端功能或构建步骤，需要在此处补充对应的运行说明。

## Git 协作约定

建议采用以下分支管理方式：

- `master`：稳定版本，保存经过检查、可演示或可交付的版本。
- `develop`：日常集成分支，用于汇总各成员的开发成果并进行联调。
- `feature/<task-name>`：功能开发分支，例如 `feature/card-event`。
- `ui/<task-name>`：界面相关任务分支，例如 `ui/manager-screen`。
- `art/<task-name>`：角色或美术素材任务分支。
- `audio/<task-name>`：语音相关任务分支。

按具体任务创建临时分支，不需要提前为所有功能创建分支。任务完成后，先合并到 `develop` 并检查；达到可演示或交付的里程碑后，再合并到 `master`。合并完成的临时分支可以删除。

## 大型文件与授权

- 对需要保留版本历史的大型二进制文件，可评估使用 Git LFS。
- 大量中间稿、缓存和可重新生成的临时文件不必全部提交。
- 提交字体、音频、第三方素材或插件前，应确认其许可允许项目使用和分发。
- 不要将 API Key、访问令牌、密码等敏感信息提交到仓库。
